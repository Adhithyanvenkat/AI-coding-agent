## 🌟 Overview

**AI Coding Agent** is an AI-powered developer assistant designed to understand existing software projects and help automate common coding tasks.

The agent analyzes the project structure, understands the available source files, processes the developer's requirements, and assists in making the required code changes.

Instead of manually searching through multiple files and determining where changes are required, the AI Coding Agent provides an intelligent workflow for analyzing and working with a software project.

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Adhithyanvenkat/AI-coding-agent.git
```

### 2. Navigate to the Project

```bash
cd AI-coding-agent
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```
